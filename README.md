# To Do List App

A simple and beautiful To Do List application built with React, Vite, and Tailwind CSS.

## Features

- Add new tasks with a title and description
- Modern UI design
- Responsive layout

## Tech Stack

- **React** (v19)
- **Vite** for fast development and bundling
- **Tailwind CSS** (v4) for utility-first styling

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and visit the local server address provided in the terminal.

## Development Notes

This project uses the `@tailwindcss/vite` plugin for seamless Tailwind CSS v4 integration.
